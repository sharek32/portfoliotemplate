#  Portfolio Website

A modern and premium portfolio template built with **HTML, CSS, and JavaScript**.  
Designed with **3D hover effects, glowing gradients, glassmorphism, dark mode toggle, and smooth animations** to give a luxurious showcase for your projects.

---

##  Features
-  Responsive design (mobile + desktop)
-  Gradient text and neon glowing buttons
-  Glassmorphism sections with smooth blur
-  Interactive 3D hover project cards
-  Dark mode toggle
-  Smooth scrolling and premium UI/UX styling
-  Easy to customize with your own projects and content
